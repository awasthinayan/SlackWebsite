🚀 Slack App – Full-Stack Real-Time Messaging Platform

A full-stack Slack-inspired messaging application built with a modern tech stack, combining a powerful backend with a beautifully animated frontend.
This project recreates the core experience of Slack while adding smooth UI animations, D3 particle backgrounds, and a polished modern interface for an impressive, production-like experience.

🌟 Features
🎨 Frontend (React.js + TailwindCSS + Framer Motion + D3.js)

⚡ Animated Landing Page with D3.js interactive particles

🌈 Gradient UI with smooth transitions

✨ Framer Motion animations for buttons, text, and page transitions

📱 Fully responsive layout

🔐 Authentication Pages (Login & Register)

💬 Chat UI inspired by Slack

🛠️ Backend (Node.js + Express + MongoDB)

🔐 User Authentication (JWT-based)

📡 Real-time messaging using WebSockets / Socket.io

🗂️ Channel & Direct Message structure

💬 Message storage and retrieval

🧰 Clean API architecture

🧱 Tech Stack

📦 Installation
git clone https://github.com/awasthinayan/SlackWebsite.git
cd SlackWebsite

Install frontend dependencies:
cd client
npm install
npm run dev

Install backend dependencies:
cd server
npm install
npm start
